Definition 7.14.

[Symmetric Game] A game matrix \(A\) is said to be symmetric if \(A\) satisfies that Rose's entry in position \((i,j)\) is always the same as Colin's entry in position \((j,i)\text{.}\) (For those who have seen linear algebra, this means that if \(R\) and \(C\) are Rose and Colin's payout matrices, we have that \(R^T = C\text{.}\))
