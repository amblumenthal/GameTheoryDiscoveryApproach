Definition 8.3.

Let \(A\) be a matrix game and \(0 \leq \delta \leq 1\text{.}\) The game \(Repeat(A, \delta)\) is defined as follows: On each round, Rose and Colin play the matrix game \(A\text{,}\) then flip a coin with probability \(\delta\) of being heads. On a heads the game continues to a next round, otherwise the game ends. The payoff for each player is the sum of the players payoffs over all of the rounds.
