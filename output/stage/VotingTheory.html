    Question 9.2.

    🔗
    In class, we established a few guidelines for ``fairness’’ in an election and developed a few election methods. As a reminder, here are the fairness criteria that Arrow’s Theorem entail:
    🔗
    1. Unanimity. If every individual prefers \(X\) to \(Y\text{,}\) the output ranking prefers \(X\) to \(Y\text{.}\)
      🔗
    2. Independence of Irrelevant Alternatives. The society’s preference on \(X\) and \(Y\) should depend only on how each voter compares \(X\) and \(Y\text{.}\)
      🔗
    3. Non-dictatorship. The output ranking is not determined by just a single voter.
      🔗
    Formally, a voting system is a function that sends a collection of preferences (or ballots) to a final ranking. Often the top of the output ranking is considered the winner (and the rest are ignored). Here are some of the voting systems that were suggested in class:
    🔗

    Definition 9.3.

    Dictatorship: After ballots are collected, pull out one ballot and that ballot determines the societal preference.
    🔗

    Definition 9.4.

    Plurality (sometimes called ``First past the post’’): collects all ballots and determines the winner by whoever has the most first place votes.
    🔗

    Definition 9.5.

    In an instant run-off, the total number of first place votes are counted for each candidate. The candidate with the least number of first place votes is removed from all ballots. This process is repeated until only one candidate remains, who is declared the winner.
    🔗

    Definition 9.6.

    Condorcet: Use the ballot rankings to simulate a head-to-head runoff between each pair of candidates. If any candidate wins all head-to-head elections, they are declared the winner. Otherwise we will say there is no Condorcet winner. (And there are many modifications that have been proposed to solve this issue.)
    🔗

    Definition 9.7.

    Borda Count:Each candidate gets points for each ballot according to values assigned to each ranking. A standard system is that last place candidates in a ballot get \(0\) points, second to last gets \(1\text{,}\) and so on. (So top ranking candidate gets \(n-1\) points from that ballot). The candidate with the highest sum of points is the winner.
    🔗
    Example of Borda Count: Suppose there are three candidates, \(A,B\text{,}\) and \(C\text{,}\) and the ballots come back as \(8\) copies of \(A>B>C\) and \(6\) copies of \(B>C>A\) and \(5\) copies of \(C>B>A\text{.}\) Then,
    🔗
    \begin{align*} \text{Points for }A \amp= 8*(2) + 6*(0) + 5*(0) = 16 \\ \text{Points for }B \amp= 8*(1) + 6*(2) + 5*(1) = 25 \\ \text{Points for }C \amp= 8*(0) + 6*(1) + 5*(3) = 21 \end{align*}
    which means that \(B\) is the Borda Count winner.
    🔗

    Question 9.9.

    🔗
    We now formalize slightly the fairness criteria above. A profile(often written \(\mathcal{P}\) or \(\mathcal{Q}\)) is the collection of all ballots. We will use \(>_\mathcal{P}\) to denote the output ordering of a voting system with profile \(\mathcal{P}\) (note this depends on the voting system). To see this, in the Borda Count example, the collection of votes would be \(\mathcal{P}\text{,}\) and the result is \(B >_{\mathcal{P}} C >_\mathcal{P} A\text{.}\)
    🔗
    We say that profiles \(\mathcal{P}\) and \(\mathcal{Q}\) agree in comparing X and Y if for every voter \(i\text{,}\) either \(i\) prefers \(X\) to \(Y\) in both profiles or \(i\) prefers \(Y\) to \(X\) in both profiles.
    🔗
    The following are called Arrow’s Axioms:
    🔗
    1. Nondictatorship. The voting system is not a dictatorship.
      🔗
    2. Unanimity. If in profile \(\mathcal{P}\) every voter prefers \(X\) to \(Y\text{,}\) then \(X >_\mathcal{P} Y\text{.}\)
      🔗
    3. Independence. If the profiles \(\mathcal{P}\) and \(\mathcal{Q}\) agree in comparing \(X\) and \(Y\text{,}\) then the output rankings \(>_{\mathcal{P}}\) and \(>_{\mathcal{Q}}\) either both rank \(X\) above \(Y\) or both rank \(Y\) above \(X\text{.}\)
      🔗
