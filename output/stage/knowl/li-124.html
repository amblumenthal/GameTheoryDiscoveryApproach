Item 3.

Now suppose a third option exists, \(Y\) such that Rose's preferences are \(X LESSTHAN Y LESSTHAN Z\) (that is, it has some value between \(0\) and \(10\)). Morgenstern and von Neumann propose that there is some \(p\) so that if \(X\) happens with probability \(p\) and \(Z\) happens with probability \(1-p\) so that \(Y\) has the same value as the lottery of \(X\) and \(Y\text{.}\) Determine (as a function of \(p\)) the value of \(Y\text{.}\)
