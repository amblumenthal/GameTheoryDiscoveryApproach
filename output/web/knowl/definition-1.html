Definition 2.1.

A game is said to be a Combinatorial Game if it is a sequential two player game with
  1. A set of possible positions (sometimes called states of the game)
  2. A move rule indicating for each position, what positions can be moved to
  3. A win rule indicating a set of terminal positions where the game ends in which each terminal position has an associated outcome (which player wins)
  4. Both players have total knowledge of the position(s), move rule, and win rule during their turn
